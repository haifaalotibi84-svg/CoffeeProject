# CoffeeProject
A simple Java project created to practice Object-Oriented Programming (OOP) concepts through a coffee shop system.
## About the Project
This project was built as a personal practice project while learning Java and OOP.
## Classes
- Coffee - Base abstract class for coffee types.
- FlavoredCoffee - Represents flavored coffee.
- IcedCoffee - Represents iced coffee.
- Customer - Represents a customer.
- Main - Runs and tests the program.
## OOP Concepts
- Abstraction
- Inheritance
- Encapsulation
- Method Overriding
- Polymorphism
## Technologies
- Java
- Eclipse IDE
## Purpose
Built for learning and practicing Java OOP concepts.
